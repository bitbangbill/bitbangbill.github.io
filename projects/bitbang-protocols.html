Bit-Banged Protocol Library

Embedded · 2024

A portable C library that implements I²C, SPI, and 1-Wire on plain GPIO, with cycle-accurate timing on Cortex-M0+ and logic-analyzer verified waveforms.

Overview

Sometimes the hardware peripheral is busy, broken, or on the wrong pins. This library drives the protocols in software with only three functions to port: set pin, read pin, and delay.

Timing is verified against each protocol's spec with a logic analyzer, and the protocol logic is unit-tested on the host with a simulated bus.

LanguageC99
ProtocolsI²C, SPI (modes 0–3), 1-Wire
TargetsCortex-M0+, Cortex-M4
Port layer3 functions
TestsHost-side, simulated bus
